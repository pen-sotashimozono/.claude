# Corrections

What the writer does with a correction from the author. In force in every
repository unless its `CLAUDE.md` lists this file under "Rules not in force".

Like `checks.md`, these are obligations of the writer, not contents of the
text. The first step is step 0 of the `sectioning` skill: say back what is
criticized.

- A correction is answered by a cut or a reorder, not by an added sentence.
  Something is added only when the reader needs a construction that is
  missing.
- "This repeats" is answered by rewriting the passage so that it says
  something new, or by not printing it. A diagram is never turned into a
  formula to avoid a repeat, and a formula is never turned into a diagram for
  that reason.
- A bare question gets an answer, not an edit. A question about meaning
  ("what does this show", "why this and not that") is answered in the reply
  first, in plain words. Use a small table where objects correspond, admit
  where the text blurred the point, and offer the one sentence that would go
  into the text. Edit only after the author picks. "Why is this written" is
  answered with the intent, the defect and a proposed fix, and then the
  writer waits.
- When the author says a passage lacks something without saying what, do not
  edit. Name the two or three gaps you can see, biggest first. Say which you
  can verify from the source, mark which are guesses, and ask which the author
  means.
- "The previous version was better": restore that version and apply the
  corrections that still stand on top of it. Add only what was asked. If both
  the last commit and an earlier draft could be meant, ask once which.
- "Is that really so?": check the primary source before defending or
  changing anything. If the author retracts, return at once to the exact
  earlier state.
- A figure the author calls tasteless or unclear is replaced, not annotated.
  Stop editing it. Say what looks wrong and propose, in words, which object
  stands at which position. Wait for the answer.
- When the author restates an explanation and says to write it so, the
  author's sentence is the one that goes in.
- An interest of the author's own ("I care because of quantum chemistry")
  tells which properties of a method to state. Those properties are stated as
  the source states them. The interest itself is not text, and no source is
  sought for it.
- A passage the author pastes back as hard to follow is an objection to its
  logic. Rebuild the order of the argument. Do not polish the wording.
- Where a fuller reading of a result is possible, offer it in the reply. The
  text gets only what the author chooses.
